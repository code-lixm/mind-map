# Simple Mind Map 更新日志

## 2026-02-03

- **核心库优化**:
  - 为 `MindMap` 初始渲染增加自动视口检查，确保内容不在视野内时自动适应画布。
  - 增强 `Render` 和 `MindMapNode` 的高亮管理逻辑，新增 `clearAllNodeHighlight` 支持 O(N) 一键清除。
  - 优化 `Drag` 插件，支持自由节点在拖拽结束时自动吸附至主树。
  - 重构 `OuterFrame` 插件，分离文字渲染层级，解决层级遮挡问题。
- **安全性与兼容性**:
  - 全面增强剪贴板（Clipboard API）工具函数，增加安全上下文（HTTPS/localhost）检测与防御性降级。
  - 优化图片复制逻辑，自动处理基础路径补全。
- **Web-plus 性能优化**:
  - 实现侧边栏按需挂载（v-if 懒加载），大幅减少首屏 `el-popover` 的预加载数量，优化内存占用。
  - 改进 `Search` 插件在只读模式下的高亮表现。
- **功能改进**:
  - 升级 `NodeNote` 节点便签：只读模式使用 `Viewer` 渲染，编辑模式支持本地图片 Base64 预览。
  - 优化 `Outline` 大纲视图与搜索框的 UI 交互及快捷键响应。
- **文档维护**: 移除与 FreedomNode 插件相关的过时开发文档，补充 `CLAUDE.md` 开发指南。
